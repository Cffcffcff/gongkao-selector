## v23 更新

报考日历整合已核查的国考、云南和四川部分考试日程，支持年度、类别、地区、状态和已关注公告筛选。共收录18项流程；仅导出起止时刻明确且尚未结束的日程，日期或月份不补造时刻。

新增独立公告阅读足迹：成功校验正文后记录，最多50条，支持搜索、清空、撤销及整站备份迁移。岗位详情与公告中心共用正文完整性校验。浏览记录仅保存在当前设备。

默认载入2027年19,426个岗位；2026年29,647个历史岗位按需加入，2027岗位详情可参考已核验的2023至2026年国考进面最低分。专业、学历学位、应届身份、证书、收藏、意向和跨年对比继续保留。

全套473项测试通过；11份已收录原表、49,073个岗位和64个公开岗位分片核对一致。全国实时采集、后台推送、跨端自动同步及完整功能清单中的其他待实现项仍需继续建设。

仓库以公开网页发布包分片部署 GitHub Pages；与腾讯云入口使用同一已审计包。发布文件不包含个人报考条件、收藏记录、私人压缩包或考生成绩明细。
