# 公考选岗网页版

手机优先打开：[腾讯云入口](https://gongkao-selector-d8eabpp26b8e63b-1499755889.tcloudbaseapp.com/)。
备用：[GitHub 网页](https://cffcffcff.github.io/gongkao-selector/)。

v13：默认只加载 2027 国考 19,426 个岗位、35,691 个名额。可主动加入 2026 年 29,647 个历史岗位、切换年份并对比最多 4 个岗位。2026 库包括全国国考、云南省考、四川部分公务员和云南部分事业单位，地方数据不是全省全量。

2026 国考官方首批进面最低分覆盖 20,227 / 20,714 个职位，云南 1,077 / 1,083 个。名单未提供笔试最高分；缺失项显示未收录，不填 0。原始分数口径和官方来源随岗位展示，不把跨年同名岗位当成相同岗位。

更多筛选 → 专业与学历：本科/学士含仅本科及本科及以上，硕士、博士同理。可开启向下查看较低学历的及以上岗位，默认关闭；仅限、上限和学历学位冲突仍生效。初筛不替代资格审核。

个人资料、收藏、意向和上传岗位仅保存于当前设备和网址，不跨设备自动同步；请使用网页内导出备份/恢复备份迁移。

本仓库仅包含已验收的公开静态网页压缩包分片、校验清单、入口和部署工作流，不含私人档案、原个人面试名单或凭据。腾讯云免费环境当前体验到期日为 2027-04-13。
