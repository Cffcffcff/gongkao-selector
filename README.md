# 公考选岗网页版

手机优先打开：[腾讯云入口](https://gongkao-selector-d8eabpp26b8e63b-1499755889.tcloudbaseapp.com/)。备用：[GitHub 网页](https://cffcffcff.github.io/gongkao-selector/)。

v14：默认只加载 2027 国考 19,426 个岗位、35,691 个名额。可主动加入 2026 年 29,647 个历史岗位，切换年份并对比最多 4 个岗位。2026 库包括全国国考、云南省考、四川部分公务员和云南部分事业单位，地方数据不是全省全量。

2026 国考官方首批进面最低分覆盖 20,227 / 20,714 个职位。用户提供工具包的 20,714 个岗位和 20,227 条最低分已逐项核对，与网站官方数据一致；资料主表 124 个“未公布”岗位可在官方名单找回。工具包及首批名单均没有每岗位笔试最高分，缺失项保持未收录，不填 0。省考及事业单位分数未收录。

新增“报考资料”：可搜索专业、证书、应届、体检与历史分数，按资料分类查看官方链接、目录版本提醒、阅读清单及空白对比表。本科与研究生代码分开说明；旧体检和体能资料提示最新官方版本。阅读进度可随网页备份迁移。

修复缺少原文的旧对比记录占满名额但无法移除的问题，保留可逐项移除占位；演示库明确提示切换官方库，不出现无效历史下载入口。

学历与学位的包含及以上、可选向下查看功能保留；当年应届、专业目录、证书与其他条件按岗位原文核对。初筛不替代资格审核。

个人资料、收藏、意向和上传岗位仅保存于当前设备和网址，不跨设备自动同步；使用网页内备份/恢复备份迁移。

本仓库仅包含验收过的公开静态网页包分片、校验清单、入口与部署工作流，不含私人档案、个人面试名单、工具包原件或凭据。
