# 公考选岗

[打开手机版与网页版](https://cffcffcff.github.io/gongkao-selector/)

2027 年官方国考岗位 19,426 个，招录 35,691 人，其中工作地点在云南的岗位 1,187 个。保留原 2026 年岗位 29,647 个，合计 49,073 个。岗位详情展示原表字段、来源行号及对应年度公告原文。

支持专业名称或代码匹配、专业类归属、证书与特殊条件筛选、考试卷别、意向、收藏和对比。手机使用单列岗位卡片与折叠筛选，可以添加到主屏幕。首次联网完整加载后，已缓存岗位和已查看公告可离线使用。

个人条件、收藏、意向和上传数据只保存在使用者设备；电脑和手机的数据分别保存，可用完整备份迁移。

2027 国考官方来源：[专题网站](http://bm.scs.gov.cn/kl2027) · [招考简章下载](http://dl.scs.gov.cn/download/8a81f6d1a129c3d401a133dca26b00d2)
