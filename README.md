# 公考选岗

岗位筛选网页，支持专业目录、学历学位、应届身份、证书、特殊条件、意向、收藏、岗位对比及招聘原文。默认只下载2027年岗位；2026年岗位可按需加入对比。打开2027年国考岗位，可参考2026、2025、2024、2023年对应或相近岗位的最低进面分。

- [国内入口](https://gongkao-selector-d8eabpp26b8e63b-1499755889.tcloudbaseapp.com/)
- [原入口](https://cffcffcff.github.io/gongkao-selector/)

本次更新（v18，2026-10-14）：新增选岗工具，集中提供官方报考日历及ICS提醒、最近50条浏览记录、报名数据录入与导入、最多20个筛选方案；岗位详情增加目标分对照。报名人数与审核通过人数分开计算竞争比，记录带截至时间与来源，用户录入和导入均标记为自填。没有接入实时报名数据或进面概率预测。

2027国考日程区分注册实名认证截止与提交申请截止。网页本身不后台推送，ICS需导入设备日历并授权提醒。目标分只比较相同满分口径，不换算100/200分。

年份、单位、岗位身份、分数口径和批次逐条核对。2026全国首批最低分已经官方名单核验；2023–2025年部分记录提供招录机关官网对照，其余保留用户资料参考。最高笔试分未公开，不推算。四川2026省考及云南事业单位只覆盖已收录地区与单位，并非全省完整库；2027省考及事业单位当前未收录。

349项测试通过，11份原岗位表和发布分片完整性核验通过。发布文件是公开网页静态包的校验分片，GitHub Actions根据release-manifest.json验证、合并、部署；两个入口使用同一发布包。个人资料、收藏、意向、浏览记录和自填统计仅保存在使用者浏览器，可通过完整备份迁移，不包含在发布包中。
