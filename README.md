# 公考选岗

[打开手机与电脑共用网页](https://gongkao-selector-d8eabpp26b8e63b-1499755889.tcloudbaseapp.com/)，[原 GitHub 网页](https://cffcffcff.github.io/gongkao-selector/)继续保留。

首次使用的个人条件全部空白，默认全国浏览。自行填写学历、专业、应届身份和证书后，可按自己的条件选岗。资料仅保存在使用者设备。已保存的资料保留；可清空并立即撤销，不影响收藏、意向和导入岗位。

当前只自动下载 2027 年国考全国首批 19,426 个岗位、35,691 个名额，不含调剂和补录。2027 年省考和事业单位岗位尚未内置，可自行导入官方职位表。专业目录、证书筛选、卷别、岗位原文、收藏和意向功能保留。

安卓和 iPhone 共用响应式网页。腾讯云入口已由用户确认关闭梯子可查看；首次测试域名提示点击“确定访问”。免费体验期至 2027-04-13，默认域名有限频，续期按腾讯云规则处理。首次联网完整加载后，已缓存的岗位与查看过的公告可离线使用。

电脑、手机和不同网址分别保存资料，可通过完整备份迁移。清除浏览器站点数据会清除本机资料。

本仓库只包含公开网页产物和部署配置，不含个人备份或登录凭据。
