# 公考选岗网页版

手机优先打开：[腾讯云入口](https://gongkao-selector-d8eabpp26b8e63b-1499755889.tcloudbaseapp.com/)。备用：[GitHub 网页](https://cffcffcff.github.io/gongkao-selector/)。

v16（2026-10-14）：默认加载 2027 国考 19,426 个岗位、35,691 个名额。点开 2027 岗位直接参考 2026 年进面最低分；展开“更早年份参考”可查看 2025、2024、2023，按年份读取，不必切换岗位库。按完整单位、用人司局、岗位名、地点、卷别与职位属性核对；唯一同码才标一致，其他相近候选逐条列出，显示报考条件变化。

2026 全国国考官方首批最低分资料覆盖 20,227 / 20,714 个岗位。2023–2025 来自用户提供工具包的岗位聚合：2023 有最低分 17,030 / 17,655；2024 为 18,383 / 18,948；2025 为 20,101 / 20,810，已去重 4 个相同岗位并补回主表缺少的 159 条最低分。云南税务三年官方抽查共 1,586 个岗位均一致，全国全表尚未独立核验，界面明确标注“用户资料参考”。100 分、200 分与无法确认的计分口径分别保留，不折算、不推算最高分；缺失分数显示“未收录”。

需要筛选旧岗位或手工比较时可主动加入 2026 年 29,647 个历史岗位，最多对比 4 个。历史库包括全国国考、云南省考、四川部分公务员和云南部分事业单位，地方数据不是全省全量。省考、事业单位历史分数暂未收录。

本次修复搜索完整部门名称找不到岗位的问题，单位筛选兼容原表部门全称与用人司局。专业、证书、学历学位、应届等筛选及收藏、意向、报考资料继续可用；默认个人条件为空。初筛不替代资格审核。

全套 309 项回归通过，三年跨年匹配逐岗位核对、数据完整性与桌面/手机页面验收通过。原始文件、个人面试名单、工具包及开发输入不发布。两站使用同一经过校验的静态包。

个人资料、收藏、意向和上传岗位仅保存在当前设备和网址，不跨设备自动同步；使用网页内备份/恢复迁移。本仓库只包含公开发布包分片、校验清单、网页入口与部署工作流，不含私人档案或凭据。
