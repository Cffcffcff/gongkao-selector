# 公考选岗

[打开手机版与网页版](https://cffcffcff.github.io/gongkao-selector/)

默认只自动下载 2027 年官方国考全国首批岗位：19,426 个岗位、35,691 个招录名额，其中工作地点在云南的岗位 1,187 个。已逐行核对原表与发布分片，不包含调剂、补录；2027 年省考和事业单位岗位尚未内置，可自行导入官方职位表。

支持专业名称或代码匹配、专业类归属、证书与特殊条件筛选、考试卷别、意向、收藏和对比。安卓和 iPhone 使用同一个响应式网页；手机显示单列岗位卡片、折叠筛选，可以添加到主屏幕。首次联网完整加载后，已缓存岗位和已查看公告可离线使用。

新版停止自动下载 2026 年岗位，首次岗位数据压缩后约 1.51 MB。用户设备内已保存的历史数据、收藏、意向和手动导入不会删除。个人数据只保存在使用者设备；电脑和手机分别保存，可用完整备份迁移。

当前入口使用 GitHub Pages，部分网络可能访问不稳定。国内直连托管仍待账号和免费额度核实，不保证该域名在所有手机网络均可访问。

2027 国考官方来源：[专题网站](http://bm.scs.gov.cn/kl2027) · [招考简章下载](http://dl.scs.gov.cn/download/8a81f6d1a129c3d401a133dca26b00d2)

本仓库只包含公开网页发布产物和部署配置，不包含个人备份或登录凭据。
