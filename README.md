## v24 更新

新增编制/用工原文筛选：在编、明确编外、其他用工、未说明与原文冲突分别展示，详情提供原文依据。不能凭事业单位或单位名称推定编制，普通聘用合同也不直接当作编外。

报名统计支持按同一年度、考试、截至时间和来源选择批次，再按报名人数、审核人数、报名竞争比或审核竞争比筛选与升降序排列。招录分析展示分布、缺失数据和其他批次，并可按竞争上限一键选岗。缺少统计或招录人数时不补造竞争比。当前主要支持用户导入的公开统计；官方自动采集仍待建设。个人统计只保存在当前设备，不随网页发布。

默认载入2027年19,426个岗位；2026年29,647个历史岗位按需加入，2027岗位详情可参考已核验的2023至2026年国考进面最低分。专业、学历学位、应届身份、证书、收藏、意向、跨年对比、公告、日历和阅读足迹继续保留。

全套512项测试通过。11份已收录原表、49,073个岗位、1,387,323个原表单元格及64个公开岗位分片核对一致；该结果仅代表已收录范围。全国实时采集、后台推送、跨端自动同步及完整功能清单中的其他待实现项仍需继续建设。

仓库以公开网页发布包分片部署 GitHub Pages；与腾讯云入口使用同一已审计包。发布文件不包含个人报考条件、收藏记录、私人压缩包、测试报名记录或考生成绩明细。
